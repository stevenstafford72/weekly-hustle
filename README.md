# Weekly Hustle 

### Problem
As a college student juggling
- Full Time Job
- Part Time Job
- School
- Family Responsibilities

I found it nearly impossible to plan my week and budget my side income. I was constantly scrambling to fit in errands for my grandpa, figure out which days to pick up work, and estimate how much I'd earn each week so I could make decisions around it. Existing apps were either too complicated or didn't combine flexible income tracking with a weekly schedule.

### Solution

Weekly Hustle is a web app that helps people juggling multiple jobs and a busy schedule plan their week and manage their income, one week at a time.

### Features
- Simple Mon–Sun view of your planned shifts
- Add shifts, including multi-day shifts
- See how much you’ll earn this week


### Tech Stack
- React (Vite)
- FastAPI
- PostgreSQL (Supabase)
- Deployed on Vercel
